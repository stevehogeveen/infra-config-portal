Designer's note

Audience

Professional operators who spend their day in Linear, Vercel and Grafana. They read dense screens quickly, expect one keyboard shortcut per primary action, and distrust any interface that hides where a number came from. Terms get a dotted-underline explanation where they first appear, so a newer technician is not left behind.

Metaphor

An operations console. A persistent left rail carries the six build steps and per-device LEDs, and it follows the state on screen: the failure example turns the server red. The centre is the workspace; a right-hand evidence drawer shows what the last read-only check returned and marks what has not been read yet; request details appear only when the app's read log supplies them. The rack is a softly glowing schematic: devices that never answered are hatched and carry no model, ports, outlets or bays.

Type pairing

Space Grotesk 600 for headings and big readouts, Inter at 13px for all UI text, IBM Plex Mono for addresses, versions, timestamps and provenance chips, so every measured value reads as a readout.

Provenance, drawn

proven 08:35 is the only green, and it is used only for what this server proved today: reached 08:35, iLO 5 v1.37, System ROM U32 v1.46. saved plan and recorded are neutral (the recorded erase carries its date and "recorded result, not a live check"), suggested is dashed, blank is dotted with a hollow glyph, so none of them depends on colour alone. Toggles use the accent, never the proof colour.
