Nothing answered

What we tried: a read-only knock on 192.0.2.27 at [time of the attempt], waiting [the app's time limit]. The real screen fills in both. What it means: the server has no power, this computer is on a different network, or the address has changed. Nothing was signed in to and nothing was changed.
Check these, in order
  1. Is the server plugged in?Its management chip answers even when the server is switched off, but not when it has no power at all. Look for any light on the front.
  2. Is this computer on the lab network?Your lab uses addresses 192.0.2.0 to 192.0.2.31. If you are on Wi-Fi, try the cable.
  3. Has the address changed?Read it off the server's front display, or ask whoever runs your network which address it was given, and update it on the left.
Other messages you might see here

Not an iLO (something else answered at that address) · Sign-in refused (wrong username or password) · No inventory permission (the sign-in worked but the account is not allowed to read the server) · Certificate not trusted (the server's certificate could not be checked; the screen explains the choice: install a trusted certificate, or turn "Verify TLS certificate" off knowing the connection stays encrypted but the server's identity is no longer checked) · Older iLO (this server is too old to be read) · Target mismatch (that address belongs to another device already in your rack). Each one gets its own screen like this, with its own things to check.

Order of work

Inspect the drives and review the hardware alerts, then approve firmware, then create the RAID, then install ESXi, then deploy Windows. The app keeps this order for you.
What does this mean?

Firmware updates are the one thing that must be approved before ESXi is installed. Approving is a review, not an install: any update is shown from the app's preview and confirmed separately.

Audience

        
A complete non-IT person, such as a lab technician or office manager, on a laptop or tablet, who has never configured a server. They read every word, so every word earns its place and every technical noun gets a plain line under it.

      

      

        
Metaphor

        
Setting up a home appliance from its companion app: a router, a thermostat, a printer. Each screen is a numbered manual page: a headline, then one big verb-sentence button with its "why", always in the first view. Everything below is reading for the curious. Proof green is only for current proof of this exact server, with its time; an older record gets an outlined "recorded result, not a live check" tag, never green.

Type pairing

        
Fraunces for headlines and page folios: a soft, warm serif that reads like a well-made instruction booklet rather than a console. Nunito for everything else: rounded and generous. Body is 17px, plain-English lines 16px, tags 15px; nothing a novice needs to read is smaller. Headlines run 44px. Addresses use the system monospace.
